# 小红书 Ultra HDR 原图

小红书原图与 Middle 画质切换，左侧浮动下载操作，支持 HDR 与普通图片原文件。

用于直接在网页端直接显示图片（HDR）原图，并提供下载当前帖子全部原图/下载单张操作。

安装：https://greasyfork.org/zh-CN/scripts/602955-%E5%B0%8F%E7%BA%A2%E4%B9%A6-ultra-hdr-%E5%8E%9F%E5%9B%BE

## 操作

仅在可见的帖子详情或图片查看器中显示屏幕左侧浮动操作栏；关闭帖子、返回首页、搜索页或个人主页列表时自动隐藏。操作栏从上到下依次为：

1. 打开原图。
2. 下载本帖全部原图 ZIP。
3. 下载原图（当前图片）。
4. 自动替换状态开关。
5. 设置。
6. 下载进度或错误信息。

设置中的浏览画质会保存到本地，刷新后仍有效：

- **Middle 1440（SDR、省流）**：默认选项，CDN 将图片缩放到最长边不超过 1440 像素并输出 JPEG。本次测试会移除增益图，不能当作 UHDR 浏览。
- **原图（保留源文件 HDR）**：直接加载原文件；源文件含可识别的增益图时，交由浏览器显示 HDR。
- **网页默认（省流）**：保留网站自己的浏览图片，仍可打开和下载原文件。

下载始终使用原文件，与浏览画质设置无关。普通 SDR 图片也可下载原图。所有模式均无需 Canvas 转码；Middle 的缩放发生在 CDN 上。单张和 ZIP 下载保留原始字节。ZIP 按网页轮播顺序编号，排除轮播克隆；能取得页码总数时核对总数，仅在全部请求成功后生成。实况图保存其静态原始对象，不额外下载独立视频流。

## 图片路径

支持 `notes_uhdr/`、`note_pre_post_uhdr/`、`spectrum/`、`notes_pre_post/`、`note_pre_post/` 目录，以及不带目录的 `1040…` 对象 ID。保留已有目录，去掉网页 CDN 的时间、签名和处理样式。头像和信息流图片不自动替换；详情轮播处理可见且宽至少 280 像素的大图。独立放大查看器的 `img.preview-interactive` 直接替换图片地址，不受该尺寸门槛限制，缩放、切图后继续生效。放大时打开和下载单张原图优先对应放大层当前图片。

原图 CDN 使用完整对象路径。没有目录的 ID 保持无目录形式，不能随意加减目录。加载失败时保留网页版本。自动替换并发最多两张。
